# OpenHASP Device Files

Status: Local device-side assets
Canonical docs: docs/features/openhasp_display/README.md

This directory contains OpenHASP device-side configuration and UI assets.

- `esp32s3-5inch/device/` — active device files (`config.json`, `printer2.jsonl`, `pages/*.jsonl`, `*.cmd`, icons).
- `archive/` — archived/experimental OpenHASP variants.

These files are not Home Assistant package YAML and are kept outside `homeassistant/packages`.

Use `docs/features/openhasp_display/` for canonical reference/design/planning documentation.

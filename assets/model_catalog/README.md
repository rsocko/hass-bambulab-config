# Local Model Catalog Staging

This directory is used for staging 3D model files and metadata before import.

**See documentation:** [docs/features/model_catalog/LOCAL-MODEL-IMPORT-GUIDE.md](../../docs/features/model_catalog/LOCAL-MODEL-IMPORT-GUIDE.md)

## Directory Structure

- **inbox/** — Place your model files here (3MF, STL, etc.) with optional YAML metadata
- **working/** — Staging area for in-progress models
- **validated/** — Successfully imported models (auto-populated by import scripts)

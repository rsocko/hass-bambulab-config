# YAML Conversion Status

This page tracks the status of dashboard YAML migration and known caveats for the printer dashboards package.

- Dashboard definitions are YAML-driven and loaded via package includes.
- Feature cards are assembled from individual package `dashboard_cards/` directories.
- Ongoing cleanup work focuses on link consistency and documentation structure.

- Prefer kebab-case file names for all documentation files.

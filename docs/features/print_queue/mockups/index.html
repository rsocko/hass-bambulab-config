Self-contained HTML mockups exploring evolutions of the unified print queue card (unified-queue-board-card.js). Each page is browser-viewable as-is. See also the original production-queue mockup and the design rationale in unified-production-queue-design.md and advanced-features-design.md.

NEW · KANBAN VIEW

Kanban board view

Adds a Kanban view mode (columns per state) to the existing list view, with drag-and-drop between columns to change state. Introduces a per-state color palette (--state-backlog … --state-done) applied subtly to cards in both views, and a prominent Time Remaining hero tile that excludes plates already marked done.

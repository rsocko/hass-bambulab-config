Queue Estimate Storyboard

This page is intentionally a storyboard, not a single screen. Each step points to the separate mockup for the real surface where that part of the workflow should happen.

Index Production Queue Add Flow Estimate Storyboard

Reading guide: the operator usually starts by adding something to the queue or opening an existing queue row. The Unified Queue board is the main place where estimates are created or refreshed. The slicer wizard is the shared execution UI. The Model Detail popup can show estimate state and offer a secondary action, but it is not the main planning surface.

Primary surface: Unified Queue Shared execution surface: Slicer wizard Secondary surface: Model Detail popup
1

Add to Queue stays lightweight

The operator can still add an item to the queue without any hidden slicer work happening in the background.

  • Add to Queue remains the normal default.
  • Add and Estimate is optional and explicit.
  • If estimate launch fails, the queue entry should still remain created.

2

Queue board owns estimate creation

This is the main planning surface. Queue rows should show whether an estimate is missing, fresh, stale, or failed, and offer the right action from that same row.

  • Estimate when no slicer estimate exists.
  • Re-estimate when the slicer estimate is stale.
  • Source and freshness should be visible without opening another screen.

3

Slicer wizard runs in estimate-only mode

The queue board or popup launches the same wizard component, but with a different intent. This is not archive creation.

  • Use the existing slicer setup and execution path.
  • Skip archive commit entirely.
  • Success copy should say the estimate was saved to the queue entry.

4

Model Detail popup shows state and a secondary action

The popup can explain estimate state for queued items and offer a recovery path, but it should not replace the queue board as the primary planning view.

  • Show minutes, source, and freshness in Queued Prints.
  • Allow Estimate via Slicer or Re-estimate when a queue entry exists.
  • Do not imply that queue add already performed slicing.

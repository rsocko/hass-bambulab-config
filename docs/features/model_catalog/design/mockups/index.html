Model Catalog · Design mockups

High-fidelity, self-contained HTML mockups for both browser cards and the model-detail popup redesign. Each page is browser-viewable as-is. Read the design rationale in catalog-card-design.md and catalog-popup-design.md.

TOOLBAR · NEW (Issue #1216)

Toolbar / header

Redesigned browser shell: sort moves into the title row, page controls move below the filter bar and center, prev/next become chevron icons, plus Models/Page selector, view-variant dropdown, Show/Hide media, Refresh, Favorites filter, and Other-Files filter. Two layout options.

 PRIMARY

Compact

Information-dense 3-column desktop grid. Thumb 120×180, queue ribbon, provenance + publish + signal chips, 3-cell metric block, filament dots, file-kind chips, capped tags.

List

Tabular row layout, 60 px rows, 11 columns. Sticky header, success rendered as a horizontal bar, bulk-select checkbox column, horizontal-scroll under 880 px.

Media

Hero-first 16:10, 2-column desktop. Queue overlay top-left, photo-count top-right, Printables-style swatch capsule bottom-right, hover-revealed carousel controls.

 POPUP · RECOMMENDED

Model Detail Popup

Hybrid summary + focused workspaces aligned with Print History semantics: compact top-right actions, media source filtering, full-size viewer affordance, thumbnail strip, and related archives panel.

Model Detail Popup (Alternative)

Split-pane inspector approach for power users: persistent left media rail and right detail/actions stack for archive triage, linking, and publish workflows.

 ADVANCED REVIEW

Candidate Review Popup

Advanced Actions-style review surface for file-to-archive candidates with confidence scoring, signal transparency, side-by-side comparison context, and bulk confirm/reject flows.
These mockups are design proposals, not deployment artefacts. They live under docs/features/model_catalog/design/ and are not loaded by Lovelace, so no _resources.yaml bump is required. The actual implementation target is homeassistant/www/3d_printing/model_catalog/model-catalog-browser-card.js.

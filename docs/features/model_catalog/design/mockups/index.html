Model Catalog · Design mockups

High-fidelity, self-contained HTML mockups for both browser cards and the model-detail popup redesign, plus the new Working Files surface redesign, the new Unified Production Queue surfaces, the new Catalog Advanced Actions popup, the new Landing Dashboard hub for issue #1174, the new Historical Print Backfill workflow for issue #1043, and external-source intake concepts. Each page is browser-viewable as-is. Landing Hub

NEW · ISSUE #1174

Landing dashboard

Dynamic operations-first home page spanning Catalog, Working Files, Intake, External Imports, and the Unified Production Queue. Focuses on actionable exceptions, recent activity, and explicit jump-to-tab routing rather than duplicating deep workflows.

 NEW · ISSUE #1174 · VARIANT A

Landing dashboard (compact)

Denser, above-the-fold variant with stronger KPI tiles, a dedicated cross-domain Key Actions block, reduced prose, and an inline grouped search-results tray.

 NEW · ISSUE #1174 · VARIANT B

Landing dashboard (analytics)

More visual operations dashboard with health rings, trend bars, confidence splits, adaptive key actions, and search results shown as grouped operator objects.

Catalog Redesign 2026-05

NEW · REDESIGN 2026-05

Catalog redesign — full mockup set

End-to-end mockups responding to the six operator user stories (frequents, Makerworld lifecycle, projects, history backfill, queue + backlog, organization). Includes default landing with Frequents rail, left-rail navigation, project view, popup hero with status pills + Publication & Sharing panel + Recover Print History wizard, extended Queue state machine, unified Add-to-Queue dialog, and the Storage & Maintenance dashboard. Companion design doc: catalog-redesign-2026-05.md.

Catalog Browser

TOOLBAR · NEW (Issue #1216)

Toolbar / header

Redesigned browser shell: sort moves into the title row, page controls move below the filter bar and center, prev/next become chevron icons, plus Models/Page selector, view-variant dropdown, always-visible Import dropdown (Browser Upload / Server Inbox), Show/Hide media, Refresh, Favorites filter, and Other-Files filter. Two layout options.

 COLLECTIONS · NEW

Collections mode

Catalog scope toggle between flat models and collections. Includes collection-card mosaics (deterministic cover derivation), hierarchy breadcrumbs, mixed-node rendering for sub-collections + direct models, and review checkpoints for hierarchy depth and membership rules.

 COLLECTIONS · SYSTEM BUCKET STUDY

No Collection preview options

Focused comparison page for the synthetic No Collection bucket: 4×4 faded field, contact-sheet strip, and scattered polaroid pile, each shown in-context against normal collection cards so the semantic fit is easier to judge.

 COLLECTIONS & PROJECTS · NEW

Collections & Projects navigation

Unified card-grid view for both Collections and Projects with scope switcher. Projects use same design language but with status badges (evaluating/active/backlog/completed) and project-specific metrics. Evaluating projects render the 3-column Kanban board on open. Addresses discovery gap where projects were rail-only in the previous design.

 PRIMARY

Compact

Information-dense 3-column desktop grid. Thumb 176×132 (4:3), queue ribbon, provenance + source + published chips (distinct icons), 3-cell metric block, filament dots, file-kind chips, capped tags.

List

Tabular row layout, 60 px rows, 12 columns including dedicated Source and Published columns. Sticky header, success rendered as a horizontal bar, bulk-select checkbox column, horizontal-scroll under 880 px.

Media

Hero-first 4:3, auto-fit grid desktop. Queue overlay top-left, photo-count top-right, Printables-style swatch capsule bottom-right, and provenance + source + published chips in the caption.

 POPUP · RECOMMENDED

Model Detail Popup

Hybrid summary + focused workspaces aligned with Print History semantics: compact top-right actions, media source filtering, full-size viewer affordance, thumbnail strip, related archives panel, related-models quick-navigation rail, and explicit collection-membership editing (chip remove + typeahead add + No Collection empty state).

Model Detail Popup (Alternative)

Split-pane inspector approach for power users: persistent left media rail and right detail/actions stack for archive triage, related-model quick hops, linking, and publish workflows.

 ADVANCED REVIEW

Candidate Review Popup

Advanced Actions-style review surface for file-to-archive candidates with confidence scoring, signal transparency, side-by-side comparison context, and bulk confirm/reject flows.

 NEW VARIANT

Model Detail Popup (Makerworld V2)

Revised split-hero popup matching the latest direction: left media carousel with type filters, right expandable model-file and plate inspector, lower linked archives plus related models and supporting files. Includes live tweak controls for width, radius, density, thumb size, accent, mobile stack, and candidate indicator.

 NEW · PHASE 0 MERGE HOST

Model Detail Popup (Phase 0 extension host)

Merged popup direction for issue #1376: preserves the updated hero and progressive section model, restores full data-panel tabs (files, archives, queue, related, supporting), and adds explicit extension host slots for #1494, #1495, #1483, and #1499. Desktop target uses a 2/5 media rail with a 3/5 details rail, with optional stacked mode retained for progressive disclosure.

 ADVANCED ACTIONS · NEW (Issue #1227)

Catalog Advanced Actions popup

Mirror of the Print History Advanced Actions popup applied to catalog models — same 5-tab nav, sub-mode drill-downs, busy/status footer, and search modal patterns. Adds the missing DELETE flow with two-stage type-to-confirm, plus soft-archive, merge-into-model, edit-fields/tags, JSON viewer, linked archive prints, duplicate-model detection, and Manyfold push/refresh. Companion design doc: catalog-advanced-actions-design.md.

EDITING · NEW (Issues #1489 #1484 #1516)

Model Detail Popup — Editing

Based on the current implementation of model-detail-popup-card.js. Shows two variants: Variant A (hybrid inline editing — tags/collections/projects as always-interactive chips, title via edit mode) and Variant B (enhanced edit form panel). Covers tag/collection/project chip UX with add/remove, Frequent & Archived toggles in the top bar, and a complete API-call legend. References #1489 (catalog_visibility), #1516 (frequent not favorites), #1484 (projects), #1227 (advanced actions), #1401 (multi-select), #1544 (top-of-page UI).

Working Files

STARTING POINT · V1

Working Files (folder-first V1)

Minimal-churn starting point. Keeps the implemented card's vertical-accordion shape, initials thumbnails, indexed pill, thumb-size toggle (SMALL/MEDIUM/LARGE), split Open in Slicer action, and per-group breadcrumb. Removes mode tabs, search, DRAFT stage chip, and Reorganize. Adds a compact sidecar strip (tags + README + .modelmeta.json reference) inside each expanded group body, plus a per-group ⋯ overflow menu for Intake Wizard / Add to Project / Add to Collection. Renames "Refresh" → "Re-index".

 ASPIRATIONAL

Working Files (folder-first, hi-fi)

Larger redesign with a left rail of folder-groups + right detail pane + full-size sidecar surface. Useful as a forward-looking target after the V1 starting point ships. Shows the synthetic (loose files) entry, the .modelmeta.json + README.md sidecar strip, and the Files | Folders toggle scoped to a selected folder-group. Authoritative design: design/working-files.md. Legacy Groups / Files / Toolbar / Group-popup mockups: archive/working-files-legacy-2026-05/.

Production Queue

QUEUE · NEW

Unified queue view

Operator-facing queue that mixes Catalog, Working, and Ideas entries while preserving the backend split. Includes Launch Pad widget, reorderable queue rows, file/plate drill-in, archive completion suggestions, and overnight/AMS planner hints.

 ADD FLOW · NEW

Add to queue

Hybrid quick-add plus advanced-add flow. Default is all files / all plates; advanced mode allows single-file or subset-of-plates selection with low-res previews, duration signals, and filament-fit hints before the entry is created.

 ESTIMATES · NEW

Queue estimate storyboard

Storyboard landing page for the estimate workflow, with links to four separate surface mockups: Add dialog, Unified Queue board, estimate-only slicer wizard, and Model Detail popup state. This page is intentionally explanatory, not a single combined screen.

 ENTRY DETAIL · UPDATED

Entry detail popup

Combined view+edit popup replacing the separate edit modal and read-only detail drawer. Inline title and state editing, tabbed Files & Plates (with per-plate mark-done) and Info & Notes. Includes simplified Idea variant and design rationale annotations.

 KANBAN VIEW · NEW

Kanban board view

Adds a Kanban view mode (columns per state) to the existing unified queue card with drag-and-drop state changes. Introduces a per-state color palette (backlog → done) applied subtly to cards in both list and kanban views, plus a prominent Time Remaining hero tile that excludes plates already marked done. Lives under docs/features/print_queue/mockups/.

Historical Print Backfill

BACKFILL · ENTRY

Recovery entry

Catalog-first launch point from model detail. Separates Create Historical Archive, Attach Source Only, and Link Existing Archive while showing archive evidence, source classification, and what state will be persisted before execution.

 BACKFILL · REVIEW

Review and persist draft

Guided review flow for worker availability, printer/process/filament validation, plate selection, and the required historical print date/time fields that must be confirmed before archive commit.

 BACKFILL · SUMMARY

Outcome and retry state

Success and partial-failure summary with the applied historical print timestamp, resulting archive linkage, source-attachment outcome, and the persisted job timeline that makes retry safe.

External Source Intake

NEW · VARIANT A

External Intake Workbench A

Three-column operations console for URL capture, extension/Stream Deck intake, confidence-aware review, and commit policy controls. Focuses on deterministic review-first operations.

 NEW · VARIANT B

External Intake Workbench B

Board-centric triage layout for larger pending queues: capture lanes, confidence chips, migration monitor, and channel-health diagnostics for high-throughput intake sessions.

 NEW · QUICK FLOW

Quick Capture Inbox

Extension + Stream Deck first workflow emphasizing rapid capture with deferred review, including channel-specific auto-routing rules and batch metadata-commit paths.

 NEW · MAKERWORLD POPUP

MakerWorld URL Import Popup

Popup-based child wizard for issue #1630 with metadata-first MakerWorld capture, warning-driven Link Only fallback, shared-intake shell reuse, and first-class Working Files destination handling for issue #1627.

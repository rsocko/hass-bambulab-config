What's gone vs the legacy mockups

  • removed Mode tabs (Groups / All Files / Ungrouped) — single view only
  • removed Group-membership chips column on file rows
  • removed + Create group from selection, + Add to group, Move to group
  • removed Bulk-selection action bar (groups no longer have a write API)
  • removed Group-edit popup (sidecars are edited on disk)
  • removed Any Manyfold link affordance

What's new in this view

  • new Synthetic (loose files) entry at the top of the group list
  • new Sidecar strip rendering .modelmeta.json (tags, primary, origin, thumbnail) + README.md
  • new Group action: Run Intake Wizard from this folder (Working Files becomes a 3rd intake source)
  • new Group actions: Add to Project, Add to Collection
  • new Title title badge when display_title overrides folder name
  • preserved Pill toolbar, teal accent, split Open button, type chips, breadcrumb folder navigation from the current card

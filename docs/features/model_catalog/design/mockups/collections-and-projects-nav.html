Navigation model: This card-grid view is accessible from two entry points:
1. Left rail: "📁 Collections" → expands to show collections tree OR "📋 Projects" section with "View all" link
2. Catalog header: "Collections" / "Projects" toggle (scope switcher shown above)

On click: Collections filter the model grid to members (existing behavior). Projects in active / backlog also filter to members, but projects in evaluating render the 3-column Kanban board (#m10 from redesign-mockups) instead, allowing the curate-then-pick workflow.

Multi-membership: A model can belong to multiple Collections and Projects simultaneously. Clicking a project chip in the model popup navigates to that project's view (consistent with Collections).

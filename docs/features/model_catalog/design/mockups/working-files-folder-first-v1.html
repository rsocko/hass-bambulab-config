Working Files — Folder-First V1 Starting Point · Minimal Churn

Conservative v1 of the folder-first redesign. Keeps the implemented card's vertical-accordion shape, group thumbnails, indexed pill, thumb-size toggle, split Open action, and per-group breadcrumb — while removing mode tabs, search, the DRAFT stage chip, the Reorganize control, and the "WORKING GROUP FILES" subheading. Adds a small sidecar strip (tags + README + .modelmeta.json reference) inside each expanded group body.

← Mockups index · working-files.md · Folder-First (aspirational) · Archived
V1 design rationale   This variant is intentionally close to today's shipping model-catalog-working-files-explorer-card.js. The card already renders one stacked card per folder-group with an initials thumbnail, count chips, and an expand/collapse chevron — v1 keeps that exact shell so the diff to the card is small. The folder-first idea shows up as: folders become the top-level entity (no Groups/All Files/Ungrouped mode), each group has one sidecar surface that explains itself (tags + README + meta-source), and the loose-files bucket is a virtual top-of-stack entry rather than a separate tab.
Kept from current UI
  • Stacked accordion of group cards; click header to expand/collapse
  • Initials-derived folder thumbnail (initialsFromTitle())
  • Indexed-pill in the toolbar; SMALL / MEDIUM / LARGE thumb toggle (violet active)
  • Per-group breadcrumb when descending into subfolders
  • Split Open in Slicer ▾ action on file rows
  • Per-group type chips (All / Models / Images / Other)
Removed from current UI
  • Groups / All Files / Ungrouped mode tabs (folder-first replaces this)
  • Global Search field (deferred; folders read naturally)
  • DRAFT / IN_PROGRESS / READY stage chip & left ribbon
  • Reorganize button + dialog
  • WORKING GROUP FILES subhead above the type chips
  • The redundant "Working Files Explorer" hero label (toolbar already titles it)
Renamed   "Refresh" → "Re-index"   Sidecar still maintains a DB-backed file inventory (path / mtime / size / hashes via POST /api/working-files/reindex). Re-index is the accurate label for what the button actually does.
Group actions   Run Intake Wizard from this folder, Add to Project, Add to Collection, Open folder… live behind a per-group ⋯ overflow menu on the header (visible whether collapsed or expanded).

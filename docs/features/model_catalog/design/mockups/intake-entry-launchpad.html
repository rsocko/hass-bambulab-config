Intake Entry Launchpad · Issue #1321

Finalized entry behavior mockup: Intake gets a prominent drop launchpad, Catalog and Working always expose an Import dropdown, and quick-drop appears only on wider layouts. Folder drop is expected to match Add Folder semantics.

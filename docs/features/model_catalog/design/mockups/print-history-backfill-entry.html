Recovery actions

Create Historical Archive

Validate the source, select the correct plate and filament mappings, review the historical print date/time, and only then commit a new canonical archive into Print History.

Persists a draft job before slicing so the reviewed timestamp and operator choices survive restarts.

Attach Source Only

Use this when the source file is useful provenance for an existing archive but you are not ready to assert a new canonical historical record.

Still records the review path, target archive, and operator note in the persisted job.

Link Existing Archive

Choose this when the historical record already exists in Bambuddy and the missing step is catalog linkage, not archive creation.

Keeps the create-vs-attach-vs-link distinction explicit in both UI and state.

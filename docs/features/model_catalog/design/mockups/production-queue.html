Queue rules

  • Default add includes all printable files and all plates.
  • Plate selection can be narrowed later or in Advanced Add.
  • Failed prints do not mark work complete.
  • Auto-complete is only applied on high-confidence archive linkage.
  • The same source can appear again later as a new queue entry.
Catalog and Working surfaces should show queue summary and jump into this view, but this is the only place where reorder, plate completion, and overnight planning are fully editable.

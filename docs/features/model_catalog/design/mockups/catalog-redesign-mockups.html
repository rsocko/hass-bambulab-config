7. Queue — Extended state machine + backlog

Adds backlog as a low-priority parking lot for "future prints". Post-print work (assembling, finishing, shipping, etc.) lives inside in progress — granular tracking via Project tasks (US-11) and BOM acquisition (US-12), not separate queue states. Re-add allowed; dequeue warns if any entry is already in progress.

14. Idea popup — Promote to Model or Working Group (US-9, Q2)

Ideas use the same popup chrome as Models, but the action row swaps print-related actions for promotion choices. Memberships carry over on promotion.

💡 Bedside organizer concept

Project: Office Decor Refresh Collection: Bedside Mods Tags: organizer · bedside

Notes

Phone + book + small drawer. Could combine with Echo Show 5 stand. Look at the Printables ones first — some have built-in cable routing which would help.

External links

printables.com/model/12345 — minimal phone dock v3
makerworld.com/models/67890 — bedside cradle

What promotion does

Promote to Model
Opens Add Model intake pre-filled with this Idea's title/notes/links. On commit, entity_type flips to model and project/collection/tag memberships carry over.
Promote to Working Group
Opens Working Group create flow pre-filled the same way. Use this when the idea materializes as a set of files you're staging rather than a single Model.

17. Popup — Publication pipeline panel (US-2b, originals & remixes)

Shown when publication.source = original or publication.draft.state ≠ none. Distinct from US-2a's contribution checklist — this is the prep pipeline for things you intend to publish outward. Rolls up #1326. Bridges to US-11 task backend via the Generate publish-prep tasks button (parallel to US-12's Generate shopping tasks). Hero pill Draft for MW · in prep is the only Catalog-grid signal — no new entity_type or card pill.

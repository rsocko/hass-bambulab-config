Working Files · Toolbar / header redesign

Three-row stack mirroring the Catalog Browser toolbar (issue #1216) so users moving between Catalog and Working Files don't relearn controls. Adds Working-Files-specific controls: Indexed pill + Reindex button, segmented view tabs, and new chips for Modified <7d and Has warnings. See working-files-card-design.md §5.

← Index | Groups Files Toolbar | Design doc

A · Default state · Groups view

Page lands here. Indexed pill is healthy. Sort defaults to Recently modified so the active set sits at the top. View tabs collapse to a tight segmented control to free toolbar real estate vs the legacy three-pill layout. Import dropdown provides mode-select jump into intake (`Browser Upload` / `Server Inbox`). Publish is visible as a first-class action from Working (`Publish to Catalog`, also known as Promote).

B · Degraded state · Indexed pill warns when a reindex is overdue

When summary.last_indexed_at exceeds a configurable threshold (default: 1 day) the pill turns amber and a hint appears next to the Reindex button. Surfaces a recurring source of confusion ("the file I just saved isn't here") without requiring an explicit alert.

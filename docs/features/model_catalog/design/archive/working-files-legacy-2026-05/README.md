# Working Files Legacy (Archived 2026-05)

These documents describe the **Working Groups** model that has been superseded by the folder-first design. They are kept for historical context only.

**Authoritative current design:** [../../working-files.md](../../working-files.md)
**Deprecation / code-removal plan:** [../../../planning/working-groups-deprecation.md](../../../planning/working-groups-deprecation.md)

## What's in this folder

| File | What it described | Why archived |
|---|---|---|
| `working-files-workflow.md` | Group-first workflow with multi-group membership, `allow_multi_group`, reorganize-on-create | Working Groups entity is removed; folder = group |
| `working-files-card.md` | Three-mode card UI (Groups / All Files / Ungrouped) | New design uses a single Working Files view |
| `working-file-spec.md` | File spec including indexing scope + group reorg rules | Indexing scope ported into `working-files.md §6`; group rules retired |
| `mockups/working-files-toolbar.html` | Toolbar mockup for the group-mode card | Replaced by single-view toolbar |
| `mockups/working-files-files.html` | All Files mode mockup | All Files mode removed |
| `mockups/working-files-groups.html` | Groups mode mockup | Groups mode removed |
| `mockups/working-files-group-popup.html` | Group create/edit popup | Group create/edit happens in Explorer now |
| `working-groups-veneer.md` (from planning/) | Plan to retain a veneer atop the group model | Underlying group model is gone |

# Print History UI And Media Docs

This folder holds popup, viewer, and media-management docs for print history.

- `archive-detail-popup-design.md` - popup structure, ownership, and phased implementation notes
- `archive-popup-timeline-design.md` - popup event-timeline contract
- `photo-capture-design.md` - multi-camera, multi-stage capture workflow
- `photo-review-design.md` - media review actions and follow-on review lifecycle work
- `manual-photo-upload.md` - phone-driven/manual upload flow
- `gcode-3d-viewer-feasibility.md` - 3D and gcode viewer options
- `viewer-render-capture-design.md` - viewer render capture workflow
- `tag-color-contract.md` - archive-tag color behavior

Start with `archive-detail-popup-design.md` for popup work and `photo-capture-design.md` for capture/upload behavior.

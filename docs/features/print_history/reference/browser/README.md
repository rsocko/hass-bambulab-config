# Print History Browser Docs

This folder holds the browser-specific documentation for print history.

- `filter-sort-design.md` - browser architecture, filtering, sorting, pagination, and scaling notes
- `multi-select-actions-design.md` - shipped multi-select browser actions for selecting visible-page prints and running bulk tag/project/favorite/delete operations
- `../design/card-chip-filter-actions.md` - issue `#860` shared contract for clickable archive-card chips that mutate browser filters
- `../design/multi-select-filter.md` - issue `#784` tags-first compact multi-select filter design and follow-on filter evaluation
- `../design/full-text-search-eval.md` - issue `#840` evaluation for Bambuddy full-text search vs the shipped browser search contract
- `top-controls-contract.md` - control-strip layout and mobile behavior contract
- `../reference/browser-instrumentation.md` - optional debugging instrumentation for the browser and heatmap
- `duplicate-filter-design.md` - duplicate classification and filter semantics
- `appdaemon-query-cache.md` - archived Variant 1/AppDaemon design notes

Start with `filter-sort-design.md` if you need the active browser contract.

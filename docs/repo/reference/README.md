# Repository Reference

This section is the canonical home for repository-level reference material.

## Structure

- `archive/` — section-local archive for superseded or historical reference docs.
  - `archive/root/` — formerly root-level markdown reports and phase notes.

## Organization Rule

- Keep repository root lightweight (prefer only `README.md` and `CHANGELOG.md` for markdown at root).
- Do **not** use a shared/common history bucket; keep archives as subfolders inside each section.
